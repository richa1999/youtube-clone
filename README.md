# YouTube Clone

A YouTube clone built using **React**, **Redux**, and **TailwindCSS**, featuring live chat, nested comments, infinite scroll, and a responsive UI.

---

## ⚙️ Features

- 🎬 Home feed with most popular videos (YouTube API v3)
- 🔍 Debounced search bar in header
- 🖥️ Responsive sidebar navigation
- ♾️ Infinite scroll for video feed
- 💬 Live chat simulation
- 🧵 Reddit-style nested comments
- 🎥 Video watch page with metadata
- ✨ Clean, responsive UI with TailwindCSS

---

## 🧱 Tech Stack

- React + React Router
- Redux Toolkit
- Tailwind CSS
- YouTube Data API v3

---

## 🔐 Environment Variables

Create a `.env` file in the root with your YouTube API key:

```bash
REACT_APP_YOUTUBE_API_KEY=your_youtube_api_key
✅ This file should not be committed. Ensure .env is listed in .gitignore.
```

🚀 Getting Started
```
Copy
Edit
npm install         # Install dependencies
npm start           # Start development server
```
